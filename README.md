# [Brain Trainer - Тренажёр мозга](https://dmitryweiner.github.io/brain-trainer)

## 📋 Описание проекта

Веб-приложение с набором мини-игр для тренировки памяти, внимания, реакции и пространственного мышления — для любого возраста, от детей до взрослых. Сложность каждой игры подстраивается под игрока. Приложение оптимизировано для телефонов и планшетов, работает без интернета и синхронизирует прогресс между устройствами.

## 🌍 Многоязычность

Приложение поддерживает четыре языка:
- 🇬🇧 **English**
- 🇷🇺 **Русский**
- 🇮🇱 **עברית** (с поддержкой RTL)
- 🇺🇦 **Українська**

Язык определяется автоматически по настройкам браузера, но может быть изменён через переключатель в шапке приложения.

## 🛠 Технологический стек

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **UI Framework**: Bootstrap 5
- **Build Tool**: Vite
- **Testing**: Vitest + React Testing Library
- **Internationalization**: react-i18next
- **Deployment**: GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`)

## 🎯 Ключевые требования

### UI/UX
- **Крупные элементы**: кнопки минимум 48×48px
- **Контрастные цвета**: соотношение контраста минимум 4.5:1
- **Крупный шрифт**: базовый размер 16-20px
- **Простая навигация**: минимум вложенности, четкие действия
- **Без hover-эффектов**: все взаимодействия через клики/тапы
- **Mobile-first**: приоритет мобильной вёрстке
- **Оптимизированные отступы**: уменьшенные padding для маленьких экранов
- **Минимум анимаций**: только необходимые для обратной связи

### Технические требования
- **Responsive**: корректная работа на экранах от 320px
- **Performance**: быстрая загрузка, оптимизация изображений
- **Accessibility**: базовые ARIA-атрибуты
- **State Management**: React Context
- **LocalStorage**: сохранение результатов и выбора языка локально

## 🎮 Игры (12 мини-игр)

1. **⚡ Reaction Click** - Тренировка скорости реакции
2. **🎨 Color Tap** - Реакция и селекция по цвету
3. **👀 Symbol Match** - Зрительное внимание (сравнение символов)
4. **🔍 Odd One Out** - Визуальный анализ (найти лишнее, сетка 3×3 → 5×5)
5. **🔢 Hidden Number** - Визуальный поиск в сетке
6. **🃏 Memory Flip** - Кратковременная память (найди пары)
7. **🧠 Sequence Recall** - Визуальная рабочая память (макс. 6 элементов)
8. **🔄 Dual-Rule Reaction** - Когнитивная гибкость
9. **⏮️ N-Back** - Рабочая память и обновление информации
10. **🔗 Logic Pair Concept** - Абстрактное мышление (с перемешиванием вариантов)
11. **📞 Phone Recall** - Числовая память (макс. 6 цифр, авто-проверка)
12. **🔎 Emoji Hunt** - Визуальный поиск эмодзи на сетке (5×5 → 6×6 → 8×8)

## 🚀 Начало работы

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

Проект будет собран в папку `dist/`. На GitHub Pages его публикует CI при каждом push в `main`; собранные файлы в репозиторий не коммитятся.

### Офлайн и установка (PWA)

Сборка включает service worker (`vite-plugin-pwa`): приложение работает без сети после первого открытия и устанавливается на главный экран. Иконки генерируются из `public/logo.svg`:

```bash
npm run icons
```

### Облачная синхронизация

Воркер Cloudflare + D1 в `cloud/` (адрес `https://brain-trainer-sync.dmitry-weiner.workers.dev`, описание — `PLAN-IMPROVEMENTS.md`, раздел 6.3). Требуется Node 22.

```bash
npm run check:cloud    # типы и контрактные тесты в Miniflare
npm run deploy:cloud   # миграции D1 и wrangler deploy
```

Адрес API для клиента можно переопределить через `VITE_SYNC_API`.

### Запуск тестов

```bash
# Запуск всех тестов
npm test

# Запуск с UI
npm test:ui

# Отчёт о покрытии
npm test:coverage
```
